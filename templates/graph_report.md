## 🗺️ How to Navigate

- `/graph explain <symbol>` — deep dive into any symbol
- `/graph callers <symbol>` — who calls/subclasses it
- `/graph path <A> <B>` — trace connections between two symbols
- `/graph entrypoints <symbol>` — nearest entrypoint(s) reaching it
- `/graph impact <symbol>` — full transitive blast radius of a change
- `/graph query "<question>"` — natural language queries
- `/graph community` — see all communities
- `/graph obsidian` — export `.codegraph/obsidian_vault/` for a native Obsidian graph view
- `/graph sync-graphdb` — export `.codegraph/graph_db/` for `/graph cypher` (optional, requires `ladybug`)
- `/graph file-deps [file|symbol]` — file-to-file dependencies (calls/inherits aggregated per file pair)
- `/graph cypher "<query>"` — arbitrary Cypher for multi-hop/aggregation questions the commands above don't cover
- `/graph snapshot <name>` — checkpoint the current graph for a later `/graph diff <name>`
- `/graph diff [name]` — what changed since the last build, or since a named snapshot
